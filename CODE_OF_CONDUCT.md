# Code of Conduct

Acyclix follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone who takes part in the project, in issues, pull requests,
discussions or anywhere else it's represented, is expected to follow it.

## Reporting

If someone's behaviour breaks this code, or makes you feel unwelcome, tell
the maintainer, [@rburns629](https://github.com/rburns629), privately: open an
issue titled "Conduct report: please contact me", with no details in it, and
you'll be contacted privately to take it from there. For a comment, issue or
pull request itself, you can also use GitHub's **Report content** on it.
Every report is reviewed, kept confidential, and answered.

Enforcement follows the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
